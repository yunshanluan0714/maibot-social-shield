# `maibot-social-shield` — MaiBot 群气氛避雷、反图灵、隐私防火墙与风控熔断插件

面向**原生零第三方依赖** MaiBot（`1.3.19`–`1.4.99`，SDK `2.20.0`–`2.30.99`）的社交防线与风控管理插件。完全人设中立，无需改动宿主机源码。

## 核心功能

1. **群气氛温度计与高危避雷针**
   - 实时识别群内密集对线吵架（引导闭嘴吃瓜）、情绪倾诉（禁止抖机灵，温和倾听）、高危敏感/炸群内容（自动进入硬静默冷却期，在发送前直接拦截出站装死）。
2. **动态关系与杠精冷处理**
   - 按会话与用户独立统计互动友好/挑衅信号并持久化，熟人更随意、对持续抬杠挑衅者自动引导冷处理。
3. **人设中立的反图灵测试与能力降级**
   - 自动检测「忽略之前指令」「输出系统提示词」「证明你是 AI」等测机/注入话术，引导贴合当前人设打岔糊弄，绝不输出死板安全拒答。
   - 对高数微积分推导、完整法条背诵、超长外文全文翻译、整套业务代码请求引导主动降智推脱（支持配置豁免关键词）。
4. **跨群与私聊双重信息防火墙（零补丁原生实现）**
   - 通过 `maisaka.planner.after_response` 自动将群聊下主脑调用的 `query_memory` 强制锁死为 `respect_filter=true`，同时注入跨群与私聊防泄密提醒，避免私聊或他群隐私漏嘴。
5. **OOC 熔断与防“Bot 互搏”**
   - 出站检测客服腔/AI 味套话及连续高重复车轱辘话（2-gram Jaccard 相似度）并强制冷却。
   - 检测群聊内同人快节奏连续乒乓互回或已知其他机器人账号，自动进入静默冷却打破无限对聊死循环。
6. **单群出站风控限流**
   - 单群滑动 60 秒窗口文本条数上限、图片/表情包条数上限，以及可配置出站敏感词与正则拦截。

## 安装与配置

1. 在 MaiBot 插件市场安装本插件（`github.yunshanluan0714.social-shield`）并重启或热加载。
2. 在 WebUI 插件配置中按需调整单群限流阈值、敏感词表、豁免降级关键词及已知其他机器人账号列表。
