# `maibot-social-shield` (v2.0.0) — OOC 熔断、防 Bot 互搏与单群风控防火墙

面向**原生零第三方依赖** MaiBot（`1.3.19`–`1.4.99`，SDK `2.20.0`–`2.99.99`）的轻量硬风控管理插件。**常态 0 Prompt 注入**、人设中立、无需改动宿主源码，聚焦真正可靠的 3 条安全底线：

## 核心功能

1. **OOC 客服腔/复读熔断 + 防 Bot 互搏**
   - 出站检测模板化 AI 客服腔以及连续高重复车轱辘话（2-gram Jaccard 相似度），触发后自动冷却静默；自动放行 `【防撤回提醒】` 等系统级通知。
   - 监测群内与同一对象的快节奏连续乒乓互回或已知其他机器人账号，自动进入静默冷却打破双机无限对聊死循环。
2. **单群出站限流与敏感词/正则拦截**
   - 单群滑动 60 秒窗口限制文本总条数与图片/表情包条数上限，并支持自定义大小写不敏感敏感词与正则表达式出站兜底拦截。
3. **跨群记忆隔离防火墙（零宿主补丁）**
   - 通过 `maisaka.planner.after_response` 在群聊场景下强制将模型调用的 `query_memory` 锁定为 `respect_filter=true`，从工具参数层阻断跨群与私聊记忆串台（无需常态注入额外提示词，也支持在配置中按需开启提示词双重兜底）。

## 安装与配置

1. 在 MaiBot 插件市场安装本插件（`github.yunshanluan0714.social-shield`）并重启或热加载。
2. 在 WebUI 插件管理页按需调整单群限流阈值、敏感词/正则表与已知其他机器人账号列表。
